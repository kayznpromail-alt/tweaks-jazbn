Setup

Claude Code Setup

Point Claude Code at your edgey API to use any supported model through your account.

PowerShell
$env:ANTHROPIC_BASE_URL = "https://api.edgey.shop/v1" $env:ANTHROPIC_API_KEY = "YOUR_API_KEY" claude
Bash / Zsh
export ANTHROPIC_BASE_URL="https://api.edgey.shop/v1" export ANTHROPIC_API_KEY="YOUR_API_KEY" claude

OpenAI-compatible API

Use the OpenAI SDK or any compatible client with edgey as the base URL.

Python
from openai import OpenAI client = OpenAI( base_url="https://api.edgey.shop/v1", api_key="YOUR_API_KEY", ) response = client.chat.completions.create( model="claude-sonnet-5", messages=[{"role": "user", "content": "Hello!"}], ) print(response.choices[0].message.content)
cURL
curl https://api.edgey.shop/v1/chat/completions \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "claude-sonnet-5", "messages": [{"role": "user", "content": "Hello!"}] }'
Anthropic SDK (Python)
import anthropic client = anthropic.Anthropic( base_url="https://api.edgey.shop/v1", api_key="YOUR_API_KEY", ) message = client.messages.create( model="claude-sonnet-5", max_tokens=1024, messages=[{"role": "user", "content": "Hello!"}], ) print(message.content[0].text)

Environment Variables

Set these environment variables to use edgey with any OpenAI-compatible tool.

PowerShell
$env:OPENAI_BASE_URL = "https://api.edgey.shop/v1" $env:OPENAI_API_KEY = "YOUR_API_KEY"
Bash / Zsh
export OPENAI_BASE_URL="https://api.edgey.shop/v1" export OPENAI_API_KEY="YOUR_API_KEY"
Command Prompt
set OPENAI_BASE_URL=https://api.edgey.shop/v1 set OPENAI_API_KEY=YOUR_API_KEY
